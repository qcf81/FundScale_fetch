# ETF 基金规模历史数据抓取与可视化分析系统

这是一个基于 Python 的 ETF 基金规模数据获取与可视化分析工具。系统自动从上海证券交易所（SSE）官方接口批量抓取各类指数 ETF（如上证50、沪深300、科创50、中证500、中证1000、创业板指等）的历史规模数据，存储至本地 SQLite 数据库，并按基金分类自动绘制多线规模走势对比图。

---

## 🌟 核心功能

1. **自动获取官方名称与数据**：直接调用上交所 API 接口，自动获取基金官方简称和历年规模数据（亿元）。
2. **多大类 ETF 分类管理**：按上证50ETF、沪深300ETF、科创50ETF、中证500、中证1000、创业板指等大类分类监控。
3. **本地数据库持久化**：使用 SQLite (`data.db`) 存储，支持增量更新与历史重载（内置主键去重）。
4. **按分类独立可视化绘图**：利用 Matplotlib 自动为每个大类生成独立清晰的折线对比图，智能配置中文字体，自动突出显示最新规模点。

---

## 📁 项目结构

```text
.
├── main.py               # 主运行入口：一键批量更新数据并启动画图程序
├── fundscale_fetch.py    # 数据抓取模块：处理 API 请求、解析并写入 SQLite 数据库
├── show_trend.py         # 图表绘制模块：从数据库读取数据，按分类生成独立走势图
├── data.db               # SQLite 数据库文件（首次运行后自动生成）
└── README.md             # 项目说明文档
```

## 🚀 快速使用

### 1. 一键运行（推荐）

直接运行主程序 `main.py`，程序会自动遍历所有配置的 ETF 代码并拉取历史记录，更新至 `data.db`，最后按分类依次弹出走势对比图并保存图片：

```bash
python main.py
```

### 2. 单独运行抓取模块

如果只需要更新或抓取某一只特定的 ETF（如 `510050`）：

```bash
# 抓取最新一期数据
python fundscale_fetch.py --code 510050

# 抓取全部历史数据
python fundscale_fetch.py --code 510050 --history
```

### 3. 单独运行画图模块

如果数据库中已包含数据，只想重新生成图表：

```bash
# 读取数据库并弹出展示各分类走势图
python show_trend.py

# 展示并把图表保存为本地图片（如 上证50ETF_trend.png）
python show_trend.py --save

# 静默生成并保存图片（不弹出图表窗口）
python show_trend.py --save --no-show
```

## ⚙️ 扩展与修改配置

如果你想增加监控的 ETF 基金，只需打开 `fundscale_fetch.py`，修改 `FUND_CATEGORIES` 字典即可：

```python
FUND_CATEGORIES = {
    "上证50ETF": ["510050", "510100", "510190", "510850", "563090"],
    "沪深300ETF": ["510300", "510330", "510360", "510310"],
    "科创50ETF": ["588000", "588080"],
    # 你可以随时添加新的分类或股票代码：
    "你的新分类": ["代码1", "代码2"],
}
```

修改后保存，再次运行 `python main.py` 即可自动生效。

## 📌 注意事项

* **数据来源**：本工具数据来源于上海证券交易所（etf.sse.com.cn）。
* **网络请求**：由于涉及多次网络请求，程序内置了重试机制，若遇到个别基金因网络波动抓取失败，不会影响其他基金的数据处理。
